    Primeros pasos

    ¿Qué es un fondo?

    Es lo que se pinta detrás del contenido de un elemento, como el papel sobre el que escribes.

    背

    Piensa en un farolillo

    Imagina una linterna de papel japonesa. El papel es el fondo y lo que está escrito encima es el contenido. En CSS pasa lo mismo: cada elemento (un div, un h1, el body...) tiene un "papel" que podemos pintar.

    Ese papel puede tener:

    • un color liso (background-color)
    • una imagen (background-image) que podemos repetir, mover y cambiar de tamaño
    • un degradado: una imagen que dibuja el propio CSS
    • varias capas a la vez, una encima de otra
    Lo más importante

    El fondo siempre va detrás del texto y de los hijos del elemento. Nunca los tapa.

    El orden de las capas

    Cuando un elemento tiene color, imagen y texto, el navegador los pinta en este orden (de abajo a arriba):

    1) primero el color, 2) encima la imagen o degradado, 3) encima de todo el contenido (texto, botones, imágenes del HTML).

    ¿Dónde escribo el CSS de los fondos?

    Igual que el resto de CSS: dentro de la regla del elemento que quieres pintar. Si quieres pintar la página entera, lo pones en body. Si quieres pintar una caja, en la clase de esa caja.

    <body> <div class="caja"> <h1>Hanami</h1> </div> </body>
    body { /* fondo de TODA la página */ background-color: #f8f5fc; } .caja { width: 400px; /* tamaño */ height: 250px; /* fondo SOLO de la caja */ background-color: #f6bfd0; }
    El error número 1

    Un div vacío mide 0 px de alto. Aunque le pongas un fondo precioso, no se verá nada. Siempre que un fondo "no funcione", lo primero es comprobar que el elemento tiene contenido o un height.

    El mapa de esta unidad

    Estas son todas las propiedades de fondo. Toca cualquiera para ir a su explicación.

    Propiedad 1

    background-color Color de fondo

    Pinta todo el fondo del elemento con un color liso.

    色
    .caja { background-color: #ea7fa0; /* rosa */ }

    Las 7 formas de escribir un color

    Todas hacen lo mismo: decir qué color quieres. Los cuadritos grises que ves detrás de algunos indican transparencia: si los ves, es que el color deja ver lo de abajo.

    ¿Cuál uso?

    hex (#ea7fa0) es el más habitual: lo copias de cualquier selector de color. rgba o hex de 8 cifras cuando quieres transparencia. hsl es el más fácil de "ajustar a mano".

    Mezclador de color

    Mueve los controles y mira cómo cambia el código. Al final, copia la línea y pégala en tu CSS.

    Propiedad 2

    background-image Imagen de fondo

    Pone una imagen (o un degradado) encima del color de fondo.

    絵
    .portada { height: 300px; /* la caja necesita altura */ background-color: #2c3270; /* color de reserva */ background-image: url("../img/paisaje.jpg"); /* la imagen */ }

    Cómo funciona la ruta de url()

    La ruta se escribe desde donde está el archivo que tiene el CSS. Este es el caso más típico en clase:

    mi-web/
    ├── index.html
    ├── css/
    │   └── estilos.css ← el CSS está aquí
    └── img/
         └── paisaje.jpg ← quiero esta

    Desde css/estilos.css hay que salir de la carpeta css (../) y entrar en img:

    url("../img/paisaje.jpg")

    Si el CSS está dentro del HTML (en una etiqueta <style>), la ruta se cuenta desde el index.html:

    url("img/paisaje.jpg")

    Si no ves tu imagen, revisa en este orden

    1) ¿La caja tiene height? 2) ¿La ruta es correcta (carpetas, ../)? 3) ¿El nombre está escrito igual, con mayúsculas y extensión (.jpg no es .png)? 4) ¿Has cerrado comillas y paréntesis?

    Pruébalo: la caja sin altura

    Esta caja tiene una imagen de fondo, pero empieza sin altura. Mueve el deslizador para darle height y mira qué pasa.

    Lo que hace la imagen si no le dices nada más

    Con solo background-image el navegador:

    1. la coloca en la esquina de arriba a la izquierda,
    2. a su tamaño real,
    3. y la repite (como baldosas) hasta llenar la caja.

    Para cambiar cada una de esas tres cosas tienes una propiedad: background-position, background-size y background-repeat.

    Fondo o etiqueta img

    Usa background-image para lo decorativo (texturas, portadas, patrones). Si la imagen es contenido importante (la foto de un producto, un retrato), va en el HTML con <img>.

    Propiedad 3

    background-repeat Repetición

    Decide si la imagen se copia como baldosas para llenar la caja o aparece una sola vez.

    繰
    Para qué se usa cada uno

    no-repeat: fotos y logos (casi siempre). repeat: texturas y patrones pequeños. repeat-x: una cenefa o franja horizontal. space y round: patrones donde no quieres ver copias cortadas.

    Propiedad 4

    background-position Posición

    Mueve la imagen dentro de la caja: arriba, abajo, centro, esquinas...

    位

    Se escriben dos valores: primero el horizontal (izquierda ↔ derecha) y después el vertical (arriba ↕ abajo).

    background-position: horizontal vertical;
    TipoEjemploQué significa
    Palabrasright bottomHorizontal: left, center, right. Vertical: top, center, bottom. Si solo escribes una (center), la otra será center.
    Píxeles40px 20px40 px desde la izquierda y 20 px desde arriba. Muy preciso.
    Porcentajes25% 75%El punto 25%/75% de la imagen se coloca en el punto 25%/75% de la caja. 0% 0% = arriba izquierda, 50% 50% = centro, 100% 100% = abajo derecha.

    Pruébalo: toca una casilla o mueve los deslizadores

    Si la imagen se repite...

    ...no notarás que se mueve, porque las copias rellenan todo. Por eso background-position casi siempre va con background-repeat: no-repeat.

    Propiedad 5

    background-size Tamaño

    Cambia el tamaño de la imagen de fondo: más grande, más pequeña o adaptada a la caja.

    寸
    ○
    cover = cubrir

    La imagen llena toda la caja sin dejar huecos. Si la forma no coincide, recorta lo que sobra. Es la que usarás en portadas y fondos de foto.

    ○
    contain = contener

    La imagen se ve entera, sin recortar. Si la forma no coincide, quedan huecos. Útil para logos o ilustraciones que no se pueden cortar.

    Pruébalo: cambia el valor y la forma de la caja

    Fíjate sobre todo en cover y contain con la caja ancha y con la caja alta.

    Antes de origin y clip

    Las 3 zonas de una caja

    Para entender las dos propiedades siguientes necesitas saber que una caja tiene capas por dentro.

    箱
    Aviso

    Aún no hemos trabajado padding ni border en clase. Aquí solo los usamos para ver las zonas; los estudiaremos a fondo más adelante.

    border-boxzona del borde
    padding-boxzona del relleno
    content-box zona del contenido
    Texto
    • content-box (blanco): donde está el texto o los hijos.
    • padding-box (rosa): el contenido + el relleno (padding), el "aire" que separa el texto del borde.
    • border-box (azul): todo lo anterior + el borde (border), la línea que rodea la caja.

    Son como cajas de bento metidas una dentro de otra. Las propiedades background-origin y background-clip te dejan elegir con cuál de las tres trabaja el fondo.

    Propiedad 6

    background-origin Punto de partida

    Decide desde qué zona se empieza a colocar la imagen (dónde está su "0 0").

    始

    En la demo, la flor está colocada en 0 0 (arriba a la izquierda) y sin repetir. Cambia el origen y mira desde dónde empieza:

    borde (border)relleno (padding)contenido
    Ojo: origin no recorta

    origin solo cambia dónde se coloca la imagen. Si quieres que el fondo no se vea en alguna zona, necesitas background-clip, la siguiente.

    Propiedad 7

    background-clip Recorte

    Decide hasta dónde se ve el fondo. Lo que queda fuera, se recorta como con unas tijeras.

    切
    origin = desde dónde se coloca · clip = hasta dónde se ve

    El borde de la demo es semitransparente para que veas si el fondo pasa por debajo o no:

    El efecto estrella: background-clip: text

    Con el valor text el fondo solo se ve dentro de las letras. Así se hacen los títulos con degradado o con una foto dentro. Es el efecto que más vas a usar, pero tiene reglas muy estrictas.

    Sakura

    ¿Quién lleva el clip: el h1 o la caja?

    Esta es la duda más habitual. La regla es sencilla:

    Regla de oro

    Las 3 líneas (background, background-clip: text y color: transparent) van todas juntas en el elemento que tiene el texto escrito dentro: el h1, el p o el span.

    Si además quieres un fondo para la tarjeta que hay detrás, ese fondo va en el padre (el div), en otra regla distinta.

    <!-- PADRE: lleva el fondo normal --> <div class="tarjeta"> <!-- HIJO: tiene el texto, lleva el clip --> <h1 class="titulo">Sakura</h1> </div>
    /* PADRE: fondo oscuro de la tarjeta */ .tarjeta { background-color: #1b1d3a; } /* HIJO: las 3 líneas, juntas */ .titulo { background: linear-gradient(90deg, #f6bfd0, #e9b85c); -webkit-background-clip: text; /* Chrome, Edge, Safari */ background-clip: text; color: transparent; }

    5 casos: cuál funciona y por qué

    Para que luzca

    Usa letras grandes y gruesas (font-size alto y font-weight: 700 o más). Con letra fina, el degradado apenas se aprecia.

    Propiedad 8

    background-attachment Fondo quieto o móvil

    Decide si el fondo se mueve o se queda quieto cuando se hace scroll.

    留

    Las tres cajas tienen el mismo fondo de rayas y el mismo texto. Pulsa Reproducir (o mueve el deslizador) para desplazar el contenido de las tres a la vez y fíjate en las rayas:

    desplazar contenido
    ValorQué hace
    scrollEl fondo está pegado a la caja. Si el contenido de dentro se desplaza, el fondo no se mueve con él.
    localEl fondo está pegado al contenido: se desplaza junto con el texto, como si estuviera impreso en el mismo papel.
    fixedEl fondo está pegado a la ventana del navegador: aunque hagas scroll en toda la página, se queda quieto. Es el efecto parallax.

    El efecto parallax con fixed

    Haz scroll en la página despacio mientras miras esta franja: la imagen se queda quieta y la caja "pasa por encima" como una ventana.

    Fondo fijobackground-attachment: fixed
    .portada { height: 300px; background-image: url("../img/paisaje.jpg"); background-size: cover; /* la imagen cubre todo */ background-attachment: fixed; /* queda quieta al hacer scroll */ }
    En el móvil

    Muchos navegadores de móvil ignoran fixed y lo tratan como scroll. Tu web seguirá viéndose bien, solo que sin el efecto.

    Escribir menos

    background El atajo

    Una sola propiedad para escribir color, imagen, posición, tamaño y repetición en una línea.

    略

    En vez de escribir cinco líneas, puedes escribir una. Pasa el ratón por cada trozo de color:

    Traductor: de atajo a propiedades sueltas

    Elige un ejemplo y mira cómo se traduce. Las dos formas dan exactamente el mismo resultado.

    Dos reglas del atajo

    1) La posición va antes que el tamaño, separados por una barra: center / cover.

    2) El resto puede ir en cualquier orden.

    La trampa del atajo

    El atajo borra todo lo que no escribes. Si pones background-size: cover; y en la línea siguiente background: url("foto.jpg");, el cover desaparece. Solución: escribe primero el atajo y después las propiedades sueltas.

    Superpoderes

    Varios fondos a la vez

    Un mismo elemento puede tener muchas capas de fondo, una encima de otra, separadas por comas.

    層
    El orden es al revés de lo que parece

    La primera capa que escribes queda arriba (delante). La última queda abajo (detrás). Como una pila de papeles: el primero que nombras es el que ves.

    Si una capa "desaparece"

    Seguramente hay otra capa opaca encima tapándola. Las capas de arriba deben tener zonas transparentes (transparent o colores con alfa) para dejar ver las de abajo.

    Imágenes hechas con CSS

    Degradados (gradients)

    Un degradado es una imagen que dibuja el propio CSS: una transición suave (o brusca) entre colores.

    虹

    Los 3 tipos

    Error típico

    background-color: linear-gradient(...) no funciona: un degradado es una imagen, no un color. Escríbelo en background o en background-image.

    1 · linear-gradient en línea recta

    linear-gradient( dirección, color 1, color 2, ...más colores )

    La dirección

    Se escribe con palabras (to right, to bottom left...) o con un ángulo en grados (deg). Si no pones dirección, va de arriba abajo. Mueve el ángulo y mira la brújula:

    Las paradas de color

    Detrás de cada color puedes escribir dónde empieza (en % o px). Si pones dos colores en la misma posición, no hay mezcla: sale un corte duro, perfecto para franjas.

    Toca cualquier muestra para copiar su código.

    2 · radial-gradient desde un centro

    radial-gradient( forma tamaño at posición, color 1, color 2 )
    • Forma: circle (círculo) o ellipse (óvalo que se adapta a la caja; es lo que sale si no pones nada).
    • Tamaño: hasta dónde llega. Puede ser una medida (circle 60px) o closest-side (hasta el lado más cercano).
    • at: dónde está el centro. Igual que background-position: at top left, at 30% 40%...

    3 · conic-gradient girando alrededor de un punto

    conic-gradient( from ángulo at posición, color 1, color 2 )
    • Los colores se reparten girando como las agujas del reloj, empezando arriba.
    • Las posiciones pueden ser grados (90deg = un cuarto de vuelta) o porcentajes (25% = un cuarto).
    • from gira el punto de partida y at mueve el centro.
    • Con cortes duros y una caja redonda (border-radius) haces gráficos de quesitos.

    4 · repeating- patrones que se repiten

    Los tres tipos tienen versión repetida: repeating-linear-gradient, repeating-radial-gradient y repeating-conic-gradient. Defines un tramo pequeño y el CSS lo repite hasta llenar la caja. La última posición marca lo que mide el tramo.

    Truco de patrones

    Un degradado pequeño + background-size + la repetición por defecto = patrón de baldosas. Así se hacen cuadros, lunares y olas japonesas. Los verás en la sección de efectos.

    Propiedad 9

    background-blend-mode Mezclar capas

    Mezcla las capas de fondo entre sí, como los filtros de una app de fotos.

    混
