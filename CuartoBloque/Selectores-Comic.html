SELECTORES

El CSS solo pinta a quien le señalas. El selector es el dedo que apunta: elige qué etiquetas reciben los estilos. En este número aprenderás a apuntar a cualquier elemento de una página… sin fallar ni un tiro.

    01

    Origen del héroe

    ¿Qué es un selector?

    Toda regla CSS tiene dos mitades: a quién se aplica y qué se le aplica. El selector es la primera mitad: un patrón que el navegador compara con cada etiqueta del HTML.

    El director de la viñeta

    Imagina que el HTML es una página de cómic llena de personajes y el CSS es el director que da órdenes: «¡Tú, el del sombrero rojo, ponte azul!». El selector es ese «tú, el del sombrero rojo»: no nombra a un personaje concreto, describe un patrón. Todos los que cumplan el patrón obedecen la orden.

    Viñeta 1Lee el HTML

    El navegador recorre el HTML y monta un árbol con todas las etiquetas: quién está dentro de quién.

    Viñeta 2Busca coincidencias

    Para cada regla, comprueba etiqueta por etiqueta si encaja con el selector. A eso se le llama hacer match.

    Viñeta 3Pinta a los elegidos

    Solo las etiquetas que encajan reciben las propiedades. Pueden ser una, cien… o ninguna.

    <h2 class="heroe">Pixel</h2>
<p class="heroe">Byte</p>
<p>Un ciudadano cualquiera</p>
    .heroe { color: crimson; }   /* 2 coincidencias: el h2 y el primer p */
.villano { color: purple; }  /* 0 coincidencias: nadie tiene esa clase */
    ¡OJO!

    Si un selector no encaja con nadie, CSS no avisa: no hay error, simplemente no pasa nada. Por eso, cuando un estilo "no funciona", lo primero que hay que sospechar es del selector.

    El vocabulario que usaremos

    Regla

    Selector + llaves con declaraciones: .heroe { color: crimson; }

    Declaración

    Cada pareja propiedad: valor; dentro de las llaves.

    Coincidir

    Una etiqueta coincide (hace match) cuando cumple el patrón del selector.

    Combinador

    Símbolo que une dos selectores: espacio, >, + o ~.

    02

    Árbol genealógico

    La familia del HTML

    Antes de apuntar hay que saber cómo se relacionan las etiquetas. El HTML es un árbol genealógico: cada etiqueta que está dentro de otra es su hija. Muchos selectores hablan de familia: padre, hijo, hermano…

    Pulsa cualquier caja

    Cada caja es una etiqueta (arriba tienes su nombre). Pulsa una y verás quién es su padre, sus hijos, sus hermanos y el resto de la familia.

    túpadreantepasadohijodescendientehermanohermano + (el siguiente)

    Pulsa una caja del escenario.

    Los parentescos

    Padre

    La etiqueta que te contiene directamente. Cada etiqueta tiene un solo padre.

    Hijos

    Las etiquetas que están justo dentro, un nivel por debajo.

    Hermanos

    Hijos del mismo padre. Están al mismo nivel, uno detrás de otro.

    Descendientes

    Todo lo que hay dentro, a cualquier profundidad: hijos, nietos, bisnietos…

    Antepasados

    Padre, abuelo, bisabuelo… hasta llegar a <html>.

    ¡OJO!

    En CSS los hermanos se miran hacia abajo: los selectores de hermanos solo alcanzan a los que vienen después. Para mirar hacia arriba (al padre o al hermano anterior) existe un selector moderno, :has(), que verás en el capítulo 8.

    03

    El equipo titular

    Selectores básicos

    Los seis que usarás todos los días. Con ellos apuntas por nombre de etiqueta, por clase o por id.

    Los seis básicos

    SelectorNombre¿A quién apunta?
    *UniversalA todas las etiquetas.
    pDe tipo (etiqueta)A todas las etiquetas <p>. Se escribe el nombre tal cual.
    .gritoDe claseA todas las que tengan class="grito". Empieza por punto.
    #portadaDe idAl único elemento con id="portada". Empieza por almohadilla.
    h3, footerAgrupaciónA los h3 y a los footer. La coma junta varios selectores en una sola regla.
    p.gritoCompuestoA los <p> que además tengan la clase grito. Todo pegado, sin espacios.

    Pruébalos. Pulsa cada selector y mira a quién le cae el ¡ZAS!. También puedes escribir el tuyo.

    ¡IDEA!

    Una etiqueta puede tener varias clases separadas por espacios: class="vineta especial". Tiene la clase vineta y la clase especial. Para exigir las dos: .vineta.especial (pegadas).

    ¿CLASE O ID?

    La clase se puede repetir; el id es único en la página. Para dar estilos usa casi siempre clases: el id "pesa" muchísimo y luego cuesta pisarlo (capítulo 11).

    ¡OJO AL ESPACIO!

    p.grito y p .grito son selectores distintos. Sin espacio: "un p que tiene la clase grito". Con espacio: "algo con clase grito que está dentro de un p". Pruébalo arriba: el segundo no encuentra a nadie.

    Y recuerda: los nombres de clase distinguen mayúsculas. .Grito no es .grito.

    04

    El equipo se une

    Combinadores

    Un combinador une dos selectores y dice qué parentesco tiene que haber entre ellos. Siempre se aplica el estilo al último selector de la cadena.

    Los cuatro combinadores

    ␣
    Descendiente · A B

    Un espacio. B que esté dentro de A, a cualquier profundidad (hijo, nieto…). .vineta p

    >
    Hijo directo · A > B

    B que sea hijo inmediato de A. Los nietos no cuentan. .vineta > p

    +
    Hermano adyacente · A + B

    El B que va justo después de A, pegado y con el mismo padre. Solo uno. h3 + p

    ~
    Hermanos generales · A ~ B

    Todos los B que vienen después de A, con el mismo padre, aunque haya otros en medio. h3 ~ p

    Fíjate en este escenario: hay párrafos a distintas profundidades. Compara .vineta p con .vineta > p, y h3 + p con h3 ~ p.

    ¡TRUCO!

    Léelos de derecha a izquierda, como hace el navegador. .vineta > p = "un p… cuyo padre es .vineta". h3 + p = "un p… que tiene justo delante un h3". El último siempre es el que se pinta.

    ESPACIOS

    Alrededor de >, + y ~ los espacios son opcionales: .vineta>p funciona igual. Pero en el descendiente el espacio es el combinador: si lo quitas, cambias el selector.

    Y se pueden encadenar: article > .vineta p = "p dentro de una .vineta que es hija de article".

    05

    Visión de rayos X

    Selectores de atributo

    Apuntan según los atributos de la etiqueta y su valor: href, type, title, lang… Se escriben entre corchetes.

    Los corchetes y sus operadores

    SelectorSignificaPara recordarlo
    [target]Tiene el atributo (da igual el valor)Solo el nombre
    [type="submit"]El valor es exactamente ese= igual que igual
    [href^="https"]El valor empieza por…^ un sombrero: va arriba, al principio
    [href$=".pdf"]El valor termina en…$ el dinero se paga al final
    [href*="numeros"]El valor contiene… en cualquier parte* la estrella: en cualquier sitio
    [class~="volador"]Una de las palabras (separadas por espacio) es…~ una palabra de la lista
    [lang|="es"]Vale "es" o empieza por "es-"Pensado para idiomas: es, es-ES, es-MX…
    USO REAL

    Su uso más habitual es en formularios: input[type="email"], input[type="checkbox"]… El tipo de etiqueta (input) más el atributo (type) para afinar.

    MAYÚSCULAS

    Los valores distinguen mayúsculas: [href$=".pdf"] no encuentra "MAPA.PDF". Añade una i antes del corchete para ignorarlas: [href$=".pdf" i].

    06

    Pseudo-clases de posición

    El hijo número 3

    Apuntan a un elemento por el lugar que ocupa entre sus hermanos: el primero, el último, el tercero, los impares… Empiezan por dos puntos: :

    Primero, último y el n.º que quieras

    Dos reglas que hay que grabarse: se empieza a contar en 1 (no en 0) y :nth-child() cuenta todos los hermanos, sean de la etiqueta que sean.

    La máquina de fórmulas · an + b

    Dentro de :nth-child() puedes escribir una fórmula. El navegador da a n los valores 0, 1, 2, 3… y se queda con los resultados que existen. Escribe una fórmula (prueba 2n+1, 3n, n+4, -n+3, odd, even o un número):

    FórmulaResultadoTruco
    odd = 2n+11, 3, 5, 7…Impares: filas de tabla alternas
    even = 2n2, 4, 6, 8…Pares
    3n3, 6, 9…Uno de cada tres
    n+44, 5, 6…Del cuarto en adelante
    -n+33, 2, 1Solo los tres primeros

    La trampa: nth-child contra nth-of-type

    p:nth-child(2) se lee: «el 2.º hijo, si además es un p». Cuenta a todos los hermanos. En cambio p:nth-of-type(2) se lee: «el 2.º p»: solo cuenta a los de su misma etiqueta. Compáralos:

    ¡CUIDADO!

    p:first-child no significa "el primer párrafo". Significa "un p que es el primer hijo". Si el primer hijo es un h3, ¡no encuentra a nadie! Para el primer párrafo usa p:first-of-type.

    07

    Pseudo-clases de estado

    Selectores que reaccionan

    Apuntan a un elemento según lo que le está pasando: el ratón está encima, tiene el foco, está marcado, es inválido… Algunos ya los conoces de las transitions.

    Interacción: hover, active, focus

    Pasa el ratón, mantén pulsado y llega al botón con la tecla Tab:

    :hover → cian · :active → se hunde · :focus-visible → marco discontinuo
    .boton:hover         { background-color: cyan; }      /* ratón encima */
.boton:active        { transform: translate(4px, 4px); } /* mientras se pulsa */
.boton:focus         { outline: 4px dashed magenta; }  /* tiene el foco (clic o Tab) */
.boton:focus-visible { outline: 4px dashed magenta; }  /* foco solo con teclado: el moderno */
    ACCESIBILIDAD

    No borres nunca el marco del foco sin poner otro: es lo único que ve quien navega con teclado. :focus-visible te deja mostrarlo solo cuando se usa el teclado, no al hacer clic.

    Formularios: el campo te avisa

    Escribe en el campo de email algo incorrecto y luego algo correcto. Marca la casilla:

    input:focus             { border-color: cyan; }     /* mientras escribes */
input:placeholder-shown { background: beige; }      /* vacío: se ve el placeholder */
input:invalid           { border-color: magenta; }  /* no cumple (email mal escrito) */
input:valid             { border-color: cyan; }     /* sí cumple */
input:disabled          { opacity: .45; }           /* tiene el atributo disabled */
input:required          { font-weight: bold; }      /* tiene el atributo required */
.casilla:checked + label { background: magenta; }   /* marcada → pinta al label de al lado */
    ¡COMBO!

    Fíjate en la última línea: .casilla:checked + label mezcla una pseudo-clase con el combinador + del capítulo 4. "El label que va justo después de una casilla marcada". Los selectores se combinan como piezas de LEGO.

    Enlaces y destino

    a:link enlace sin visitar · a:visited ya visitado. Si los usas con hover y active, respeta el orden LoVe HAte: Link, Visited, Hover, Active. Si no, unos pisan a otros.

    :target apunta al elemento cuyo id aparece en la dirección tras la #. Pulsa el enlace:

    Ir a #sorpresa

    08

    La nueva generación

    :not, :is, :where y :has

    Cuatro pseudo-clases que reciben otros selectores entre paréntesis. Funcionan en todos los navegadores actuales y ahorran muchísimo código.

    Los cuatro superpoderes

    :not( )

    Todos menos los que cumplan lo de dentro. .carta:not(.agotado) = las cartas que no están agotadas.

    :is( )

    Cualquiera de la lista. :is(article, aside) h3 = article h3, aside h3, pero más corto.

    :where( )

    Igual que :is(), pero no pesa nada (especificidad 0). Ideal para estilos base fáciles de pisar.

    :has( )

    El elemento que contiene algo. .carta:has(.oferta) = las cartas que tienen una oferta dentro. ¡Por fin se puede mirar hacia arriba!

    :has() MOLA

    Con :has() pintas al padre según sus hijos, algo imposible hasta hace poco. Y con h3:has(+ .oferta) apuntas al hermano anterior: "el h3 que tiene justo después una .oferta".

    :has() en vivo

    Marca las cartas que quieras. La carta entera cambia porque .carta:has(input:checked) mira si tiene dentro una casilla marcada:

    .carta:has(input:checked) {   /* la carta que contiene una casilla marcada */
  background-color: gold;
  transform: rotate(-2deg) translateY(-6px);
}

    Bonus moderno: el anidamiento con &

    El CSS actual permite escribir reglas dentro de otras, como en el HTML. El & significa "el selector de fuera". Así agrupas todo lo de un componente en un solo bloque:

    .carta {
  border: 3px solid black;
  & h4 { font-size: 160%; }        /* = .carta h4 */
  & .precio { color: magenta; }    /* = .carta .precio */
  &:hover { transform: scale(1.04); } /* = .carta:hover */
}
    .carta { border: 3px solid black; }
.carta h4 { font-size: 160%; }
.carta .precio { color: magenta; }
.carta:hover { transform: scale(1.04); }

    Pixel #4

    4 €

    Pasa el ratón: este estilo está escrito con anidamiento.

    OJO CON &:hover

    &:hover (pegado) = .carta:hover. Pero & :hover (con espacio) = "cualquier descendiente de .carta con hover". El espacio sigue siendo un combinador.

    09

    Los personajes invisibles

    Pseudo-elementos

    No apuntan a una etiqueta, sino a una parte de ella (su primera letra, su primera línea…) o crean cajas nuevas que no existen en el HTML. Se escriben con dos puntos dobles: ::

    Un punto o dos

    :pseudo-clase

    Un estado o una posición del elemento entero: :hover, :nth-child(3), :checked…

    ::pseudo-elemento

    Una parte del elemento o una caja extra: ::before, ::first-letter, ::placeholder…

    Todos en vivo

    Era una noche oscura en Ciudad Píxel. La primera letra de este párrafo es gigante y toda la primera línea va en negrita, pero no hay ninguna etiqueta extra en el HTML: lo hacen ::first-letter y ::first-line. Cambia el ancho de la ventana y verás que la negrita sigue siempre a la primera línea.

    Las comillas de esta frase las pone el CSS

    • son ::marker

    Selecciona este texto con el ratón: ::selection lo pinta de amarillo.

    .historia::first-letter { font-size: 300%; color: magenta; } /* la primera letra */
.historia::first-line   { font-weight: bold; }                /* la primera línea */
.cita::before { content: "«"; }        /* caja nueva al PRINCIPIO del contenido */
.cita::after  { content: "»"; }        /* caja nueva al FINAL del contenido */
.nuevo { position: relative; }
.nuevo::after { content: "¡NUEVO!"; position: absolute; top: -14px; right: -14px; }
.lista li::marker  { content: "★ "; color: magenta; } /* la viñeta de la lista */
input::placeholder { color: magenta; }                /* el texto de ejemplo */
.texto::selection  { background-color: gold; }        /* lo que seleccionas */
    ¡SIN CONTENT NO HAY NADA!

    ::before y ::after necesitan la propiedad content, aunque sea vacía (content: "";). Sin ella, no aparecen.

    Se crean dentro del elemento (antes y después de su contenido), no fuera. Y no metas ahí texto importante: no se puede seleccionar ni lo leen bien todos los lectores de pantalla.

    10

    De padres a hijos

    La herencia

    Algunas propiedades que le pones al padre bajan solas a todos sus descendientes, sin necesidad de selector. Otras se quedan solo en el padre. Saber cuáles te ahorra muchas reglas.

    ¿Qué se hereda? Compruébalo

    Activa propiedades en el padre (la caja punteada) y mira qué les pasa a los hijos. Ningún hijo tiene estilos propios, salvo la caja blanca, que tiene su propio fondo.

    Pixel (h4)

    Un párrafo con un enlace dentro.

    Una caja con fondo propio
      Se heredan ✓

      Las del texto: color, font-family, font-size, font-weight, font-style, line-height, text-align, letter-spacing, list-style…

      No se heredan ✗

      Las de la caja: border, padding, margin, background, width, height, display, position, transform…

      TRUCO PRO

      Por eso se suele poner la fuente y el color en el body: toda la página los hereda. Pero los button e input no heredan la fuente. Arréglalo con una línea: button, input { font: inherit; }

      Palabras clave para controlar la herencia

      inherit

      "Copia el valor de mi padre", aunque la propiedad no se herede sola. border: inherit;

      initial

      "Vuelve al valor de fábrica de CSS". color: initial; → negro.

      unset

      "Hereda si se hereda; si no, valor de fábrica".

      ¡OJO!

      Lo heredado es lo más débil de CSS. Si le das color: red a un div y existe una regla p { color: blue; }, los párrafos de dentro salen azules. Cualquier regla que apunte al hijo directamente, aunque sea *, gana a la herencia.

      11

      El gran combate

      ¿Quién gana? Especificidad

      Cuando dos reglas apuntan al mismo elemento y se contradicen (una dice rojo y otra azul), CSS tiene que elegir. Lo decide la cascada, y su arma principal es la especificidad: cuánto "pesa" cada selector.

      Las tres preguntas de la cascada

      Pregunta 1¿Hay !important?

      Una declaración con !important gana a las que no lo tienen. Es un arma nuclear: úsala casi nunca.

      Pregunta 2¿Quién pesa más?

      Si siguen empatadas, gana el selector con más especificidad.

      Pregunta 3¿Quién va después?

      Si pesan lo mismo, gana la regla escrita más abajo en el CSS.

      El marcador: ID · CLASE · TIPO

      La especificidad es un marcador de tres columnas. Cada parte del selector suma un punto en su columna:

      Columna ID

      Cada #id.

      Columna CLASE

      Cada .clase, [atributo] y :pseudo-clase.

      Columna TIPO

      Cada etiqueta (p, div…) y cada ::pseudo-elemento.

      ¡NO SE SUMA!

      Se compara columna a columna, de izquierda a derecha, como un marcador de goles por rondas. En cuanto una columna es mayor, gana, sin mirar las demás. Por eso #a (1,0,0) gana a .b.c.d.e.f.g.h.i.j.k.l (0,11,0).

      No cuentan nada: *, los combinadores (espacio, >, +, ~) y :where(). Los :is(), :not() y :has() valen lo que su selector más fuerte de dentro. Y un style="…" escrito en el HTML gana a todos los selectores.
