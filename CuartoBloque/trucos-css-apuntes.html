1box-sizing: border-box

Cambia la forma en que el navegador calcula el tamaño real de una caja. Es probablemente el truco que más problemas de maquetación resuelve.

¿Qué problema resuelve?

Por defecto, todos los elementos usan box-sizing: content-box: el width y el height que escribes solo afectan al contenido. El padding y el border se suman por fuera. Así, una caja con width: 200px y padding: 20px acaba ocupando 240px en pantalla.

Con box-sizing: border-box el width incluye contenido + padding + borde. La caja mide exactamente lo que tú dices, aunque luego cambies el padding.

Paso a paso

  1. Declara una caja con width: 200px, padding: 20px y border: 5px solid.
  2. Con content-box: 200 (contenido) + 40 (padding izq. + der.) + 10 (bordes) = 250px en pantalla.
  3. Con border-box: el navegador reserva 200px totales y reduce el contenido a 200 − 40 − 10 = 150px.
  4. Resultado: puedes poner dos cajas de width: 50% con padding y borde, y siguen cabiendo en una fila.
/* Reset universal recomendado */
*,
*::before,
*::after {
  box-sizing: border-box;
}

.tarjeta {
  width: 200px;
  padding: 20px;
  border: 5px solid #333;
  /* Ocupa 200px en total, no 250px */
}
Resultado
content-box (250px)
border-box (200px)
Consejo: Ponlo siempre al principio de tu hoja de estilos. Incluir ::before y ::after en el selector hace que también los pseudoelementos se comporten igual.

2Centrado con position absolute + transform

Centra un elemento horizontal y verticalmente respecto a su contenedor sin conocer su tamaño.

Concepto

top: 50% y left: 50% colocan la esquina superior izquierda del elemento en el centro del contenedor, no el elemento entero. Para corregirlo hay que desplazarlo hacia atrás la mitad de su propio tamaño. Eso es lo que hace transform: translate(-50%, -50%): los porcentajes de translate se calculan sobre el tamaño del propio elemento, por lo que no hace falta saber cuánto mide.

Paso a paso

  1. El contenedor lleva position: relative para que sea el punto de referencia.
  2. El hijo lleva position: absolute, que lo saca del flujo normal.
  3. top: 50%; left: 50% → su esquina superior izquierda queda en el centro del padre.
  4. transform: translate(-50%, -50%) → se mueve la mitad de su ancho a la izquierda y la mitad de su alto hacia arriba. Queda centrado.
.contenedor {
  position: relative;
  height: 300px;
}

.centrado {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
Resultado
Centrado
Ojo: Un elemento con position: absolute no ocupa espacio en el flujo, así que el contenedor no crece con él. Úsalo con cuidado; para la mayoría de casos actuales, Flexbox o Grid son más limpios.

3Centrado con Flexbox

La versión moderna y más sencilla de centrar contenido en dos ejes.

Al poner display: flex en el contenedor, sus hijos pasan a ser elementos flex. justify-content alinea sobre el eje principal (horizontal por defecto) y align-items sobre el eje transversal (vertical por defecto).

  1. display: flex activa el modo flexible en el padre.
  2. justify-content: center centra los hijos horizontalmente.
  3. align-items: center los centra verticalmente.
  4. El contenedor necesita altura (por ejemplo min-height: 100vh) para que el centrado vertical sea visible.
.flexcenter {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* Variante corta con Grid */
.gridcenter {
  display: grid;
  place-items: center;
  min-height: 100vh;
}
Resultado
Centrado

4Unidades de viewport: 100vh y min-height: 100vh

Permiten que un elemento ocupe el alto (o ancho) de la ventana del navegador.

1vh es el 1% del alto de la ventana (viewport height) y 1vw el 1% del ancho. Por tanto 100vh es exactamente la altura visible.

  • height: 100vh → el elemento mide siempre lo que la ventana. Si el contenido es mayor, se desborda.
  • min-height: 100vh → mide como mínimo la ventana, pero puede crecer si hay más contenido. Suele ser la opción más segura.
.portada {
  min-height: 100vh;   /* pantalla completa, sin recortar contenido */
}

/* Footer siempre abajo aunque haya poco contenido */
body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
main { flex: 1; }
Consejo: En móviles la barra de direcciones cambia la altura visible. Existen 100dvh (altura dinámica) y 100svh (altura pequeña) para resolverlo.

5calc(): operaciones matemáticas en CSS

Permite calcular valores de propiedades mezclando unidades distintas. Es la herramienta clave para resolver situaciones que con un solo valor fijo son imposibles.

¿Qué es y por qué es tan útil?

Con calc() el navegador resuelve la operación en tiempo de renderizado, cuando ya conoce el tamaño real del contenedor y de la ventana. Por eso puedes mezclar valores relativos (%, vh, vw, rem) con valores absolutos (px), algo que ninguna unidad por sí sola permite.

Ejemplo típico: quieres que el contenido ocupe todo el alto de la pantalla menos una cabecera fija de 80px. No puedes escribir 100vh - 80px a pelo; sí puedes con calc(100vh - 80px).

Sintaxis y reglas

  • Operadores: +, -, * y /.
  • + y - necesitan un espacio a cada lado. calc(100% - 20px) funciona; calc(100%-20px) o calc(20vw+50px) no funcionan. Es el error más habitual.
  • * y / no requieren espacios, pero conviene ponerlos por legibilidad.
  • En una multiplicación, al menos uno de los factores debe ser un número sin unidad (calc(10px * 3)). En una división, el divisor debe ser un número sin unidad (calc(100% / 3)).
  • No se escribe calc: (...); se usa como valor de una propiedad: width: calc(...).
  • Se pueden anidar paréntesis para controlar el orden: calc((100% - 40px) / 2).
  • Se puede usar con variables CSS: calc(var(--gap) * 2).

Caso 1: alto de pantalla menos cabecera

Paso a paso: el navegador toma el alto de la ventana (100vh), le resta 80px y asigna el resultado al elemento. Si la ventana cambia de tamaño, el cálculo se rehace automáticamente.

header { height: 80px; }

main {
  height: calc(100vh - 80px);
  overflow-y: auto;
}

Caso 2: anchura fluida con margen fijo

Una caja que ocupa todo el ancho menos 40px de margen lateral (20px por cada lado).

.caja {
  width: calc(100% - 40px);
  margin: 0 auto;
}
Resultado
width: calc(100% - 40px)

Caso 3: columnas con separación exacta

Tres columnas iguales con 20px de hueco entre ellas. El ancho total de huecos es 2 × 20 = 40px, se restan al 100% y el resto se divide entre 3.

.fila { display: flex; gap: 20px; }

.col {
  width: calc((100% - 40px) / 3);
}

Caso 4: mezclar unidades relativas y absolutas

.titulo {
  font-size: calc(1rem + 2vw);      /* texto que crece con la ventana */
}

.hero {
  width: calc(20vw + 50px);          /* con espacios alrededor del + */
}

Caso 5: calc() con variables CSS

:root {
  --cabecera: 80px;
  --pie: 60px;
}

.contenido {
  min-height: calc(100vh - var(--cabecera) - var(--pie));
}

Cambias el valor en un solo sitio y todos los cálculos se actualizan.

Funciones relacionadas

  • min(a, b): elige el menor de dos valores. width: min(90%, 800px) → nunca pasa de 800px.
  • max(a, b): elige el mayor.
  • clamp(mín, ideal, máx): valor flexible con límites. font-size: clamp(1rem, 2.5vw, 2rem).
Consejo: Regla práctica: si necesitas restar o sumar píxeles a un porcentaje o a una unidad de viewport, la respuesta es calc().

6Depurar maquetación con outline

Un selector universal con contorno muestra dónde empieza y termina cada caja.

A diferencia del border, el outline no ocupa espacio ni altera el tamaño de las cajas, así que puedes activarlo sin descolocar el diseño.

* {
  outline: 1px solid grey;
}

/* Cada nivel de anidamiento con un color distinto */
* { outline: 1px solid rgba(255, 0, 0, .4); }
* * { outline-color: rgba(0, 128, 0, .4); }
* * * { outline-color: rgba(0, 0, 255, .4); }
  1. Añade la regla temporalmente.
  2. Localiza qué caja se sale, se solapa o tiene un ancho inesperado.
  3. Combínalo con el inspector del navegador (pasar el ratón sobre un elemento muestra margin, border y padding).
  4. Elimina la regla cuando termines.

7Pseudoelementos ::before y ::after con content

Añaden elementos decorativos sin ensuciar el HTML con divs o spans extra.

::before inserta un elemento virtual antes del contenido de una etiqueta y ::after después. Solo se generan si defines la propiedad content (aunque sea vacía: content: ""). Por defecto son inline, por lo que suele hacer falta darles display: block o position: absolute para darles tamaño.

  1. Elige el elemento (.boton) y dale position: relative.
  2. Crea el pseudoelemento con content: "".
  3. Dale position: absolute, tamaño y color.
  4. Colócalo con top/left/right/bottom.
.titulo {
  position: relative;
  padding-bottom: 10px;
}

.titulo::after {
  content: "";
  position: absolute;
  left: 0;
  bottom: 0;
  width: 60px;
  height: 4px;
  background: crimson;      /* subrayado decorativo */
}

.enlace::before {
  content: "→ ";            /* icono de texto */
}
Resultado

Título con subrayado

Consejo: Se pueden combinar dos niveles, por ejemplo .caja::before para un fondo y .caja::after para un adorno: con ambos tienes dos elementos decorativos "gratis" por etiqueta.

8Fila de cajas con float + border-box

Una especie de cuadrícula unidimensional con anchos porcentuales, útil en proyectos con compatibilidad antigua.

Con float: left las cajas se colocan una junto a otra. Gracias a border-box, el padding y el borde no rompen la suma de porcentajes: 10% + 30% + 60% = 100% exactos.

.core {
  float: left;              /* sin esto, las cajas se apilan */
  box-sizing: border-box;
  border: 1px solid black;
}
.pdg { padding: 20px 0 10px; height: 60px; }

/* HTML */
<div style="text-align:center">
  <div class="pdg core" style="width:10%">10%</div>
  <div class="pdg core" style="width:30%">30%</div>
  <div class="pdg core" style="width:60%">60%</div>
</div>
Ojo: Los floats sacan a los hijos del flujo y el contenedor colapsa a altura 0. Hay que "limpiar" con clear: both o un clearfix. Hoy se prefiere Flexbox o Grid.

9inline-block sin huecos (font-size: 0)

Alternativa a los floats para colocar cajas en línea con ancho definido.

display: inline-block hace que cada caja se comporte como una palabra (se coloca en línea) pero acepte width, height, margin y padding. El problema: el espacio en blanco entre etiquetas del HTML se interpreta como un espacio de texto, y dos cajas del 50% no caben en una línea porque suman 100% más ese hueco.

  1. Se pone font-size: 0 en el contenedor: el espacio entre etiquetas pasa a medir 0.
  2. En cada hijo se restablece el tamaño de fuente (font-size: 1rem), porque lo hereda.
  3. Los hijos con display: inline-block; width: 50% ahora caben exactamente en la misma línea.
.container {
  font-size: 0;
  margin: 0;
  padding: 0;
}

.container .col-1,
.container .col-2 {
  display: inline-block;
  font-size: 1rem;      /* recuperar el tamaño de texto */
  width: 50%;
  vertical-align: top;
}
Resultado
50%
50%

10box-shadow inset y text-shadow

Efectos visuales de profundidad sin usar imágenes.

box-shadow: inset dibuja la sombra dentro de la caja, lo que da aspecto de botón pulsado o campo hundido. text-shadow aplica sombra al texto. Ambos siguen la sintaxis desplazamiento-x desplazamiento-y desenfoque color.

.boton {
  box-shadow: inset 0 2px 4px rgba(0, 0, 0, .3);
}

.boton:active {
  box-shadow: inset 0 4px 8px rgba(0, 0, 0, .5);
}

h1 {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, .4);
}
Resultado Texto

11Feature queries: @supports

Aplican estilos solo si el navegador soporta una propiedad concreta.

Sirven para hacer mejora progresiva: primero defines un estilo básico válido en todos los navegadores y después añades el avanzado dentro de @supports. Los navegadores que no lo entienden lo ignoran sin romper nada.

.tarjeta { background: #eee; }          /* base para todos */

@supports (display: grid) {
  .galeria {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
  }
}

@supports (filter: blur(2px)) {
  .fondo { filter: blur(2px); }
}

12Selectores nth-child con rangos ("mod queries")

Seleccionan elementos de una lista según su posición.

:nth-child(an+b) selecciona los hijos cuya posición cumple la fórmula, donde n va tomando los valores 0, 1, 2… Combinando :nth-child(n+3) y :nth-last-child(n+3) se pueden seleccionar rangos o cambiar el diseño según cuántos elementos hay.

  • li:nth-child(2n) → posiciones pares.
  • li:nth-child(n+4) → del cuarto en adelante.
  • li:nth-child(-n+3) → los tres primeros.
  • li:first-child:nth-last-child(3), li:first-child:nth-last-child(3) ~ li → los elementos de una lista que tiene exactamente 3.
li:nth-child(-n+3) { font-weight: bold; }

/* Si la lista tiene exactamente 3 elementos, cada uno ocupa un tercio */
li:first-child:nth-last-child(3),
li:first-child:nth-last-child(3) ~ li {
  width: calc(100% / 3);
}
Consejo: Hoy Flexbox y Grid resuelven la mayoría de estos casos, pero conocer nth-child sigue siendo imprescindible para listas, tablas y galerías.

13Flexbox y CSS Grid: los aliados

Los dos sistemas de maquetación modernos que reemplazan a floats e inline-block.

  • Flexbox: maquetación en una dimensión (fila o columna). Ideal para barras de navegación, centrar y repartir espacio.
  • Grid: maquetación en dos dimensiones (filas y columnas a la vez). Ideal para la estructura general de la página.
.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
