    Puesto 1 · la despensa

    :root y las variables CSS

    Imagina la despensa de la feria: cada tarro tiene una etiqueta y dentro guarda algo. Una variable CSS (su nombre oficial es custom property, propiedad personalizada) es eso: un nombre con un valor dentro. Lo escribes una vez y lo usas en toda la página.

    Se crea con dos guiones

    --verde-hoja: #2f9e44; El nombre empieza siempre por -- y distingue mayúsculas: --Verde y --verde son tarros distintos.

    Se usa con var()

    color: var(--verde-hoja); El navegador abre el tarro y pone su contenido en esa línea.

    Se guarda en :root

    :root es la raíz del documento (la etiqueta <html>). Lo que se declara ahí lo heredan todos los elementos de la página.

    La gran ventajaCambia --rojo en :root y cambian todas las sombras de la página a la vez. Sin variables tendrías que buscar ese color en cien sitios.

    Las variables se heredan y se pueden redefinir

    Una variable funciona como color o font-family: se hereda de padres a hijos. Y si la vuelves a declarar en un elemento, ese elemento y sus hijos usan el valor nuevo. Así se hacen variantes de un mismo componente cambiando solo una línea:

    Variables que cambian al pasar el ratón

    Una variable distinta en cada elemento

    Las variables también se pueden poner en el atributo style del HTML. Es la forma más limpia de dar a cada elemento un dato propio (su color, su retraso, su porcentaje) sin escribir una clase para cada uno:

    El tarro de reserva

    Valor de reserva

    var(--borde, 2px): si --borde no existe, usa 2px. Muy útil en componentes que se copian a otros proyectos.

    Variables dentro de variables

    --sombra: 4px 4px 0 var(--tinta); Una variable puede contener otras. Si cambias --tinta, cambia también la sombra.

    Con calc()

    calc(var(--espacio) * 2) permite hacer cuentas con lo que hay en el tarro. Lo viste a fondo en Gotham (bloque 04).

    Tres trampas de las variables 1. No funcionan dentro de la condición de una media query: @media (min-width: var(--movil)) no hace nada.
    2. No se pegan con unidades: var(--n)px no da «16px». Se escribe calc(var(--n) * 1px).
    3. Si el valor no encaja con la propiedad (--color: 20px en un color), el navegador no vuelve a la línea anterior: se comporta como unset (hereda el valor del padre si la propiedad se hereda, como color, y si no, usa su valor inicial). Revisa los tarros si algo sale de un color inesperado o transparente.

    Puesto 2 · la caja de herramientas

    Iconos con Font Awesome

    Font Awesome es una colección de miles de iconos que se usan como si fueran letras: se cargan con una hoja de estilos y se ponen con una etiqueta <i> y unas clases. Como son texto, cambian de tamaño con font-size y de color con color, sin perder calidad.

    Paso 1 · Enlazarlo desde cdnjs

    1. Entra en cdnjs.com/libraries/font-awesome y elige la versión 6.4.0, la que usamos en clase. (Hay versiones más nuevas; las clases de este bloque funcionan igual en toda la serie 6.)
    2. Copia el enlace de all.min.css (todos los estilos de iconos, comprimidos).
    3. Pégalo dentro del <head> de tu HTML, antes de tu propia hoja de estilos.

    Paso 2 · Buscar el icono en el catálogo

    El catálogo oficial está en fontawesome.com/icons. Marca el filtro Free (los iconos Pro son de pago y no se ven con el enlace gratuito). Al pulsar un icono, el catálogo te da su código para copiar.

    Animaciones listas para usar

    Font Awesome usa variablesLas animaciones se ajustan con variables propias: --fa-animation-duration, --fa-beat-scale, --fa-bounce-height… Es justo lo que acabas de aprender en el puesto 1. Además, Font Awesome detiene sus animaciones si el sistema pide menos movimiento (prefers-reduced-motion).

    Iconos accesibles

    Icono decorativo

    Si el texto ya lo dice todo, pon aria-hidden="true" en el <i>: el lector de pantalla no leerá un símbolo raro.

    Botón solo con icono

    Sin texto visible, el botón necesita un nombre: aria-label="Buscar" en el botón y aria-hidden en el icono.

    Color con currentColor

    El icono toma el color del texto que lo rodea. Si el enlace cambia de color en :hover, el icono lo sigue solo.

    Interludio · el rotulista

    Texto degradado

    Un texto no puede tener un degradado como color: color solo admite colores lisos. El truco es otro. Se pone el degradado como fondo, se recorta ese fondo con la forma de las letras y se vuelven las letras transparentes para que se vea el fondo a través.

    1. Un color de reserva: color: #e23d28; Si algo falla, el texto se lee igualmente.
    2. El degradado de fondo: background: linear-gradient(90deg, rojo, amarillo, verde);
    3. Recortarlo con las letras: -webkit-background-clip: text; y background-clip: text; Se escriben las dos: la versión con prefijo es la que entienden los navegadores antiguos.
    4. Letras transparentes: color: transparent; Esta línea va después del color de reserva, así que gana.
    5. Si el título ocupa toda la línea, el degradado se estira a todo el ancho. Con display: inline-block se ajusta al texto.
    Dos tropiezos 1. Letras que se cortan por abajo (la «g», la «y»): el fondo solo llega hasta el final de la caja. Añade un poco de padding-bottom o sube el line-height.
    2. Al seleccionar el texto, algunos navegadores lo muestran raro. Si lo usas en párrafos largos, mejor no: déjalo para títulos.

    Puesto 4 · los letreros

    Crear un menú de navegación

    Todos los menús de esta sección comparten el mismo esqueleto HTML. Aprende el esqueleto una vez y luego solo cambia el CSS:

    1. <nav>: le dice al navegador (y a los lectores de pantalla) que dentro hay navegación. Si hay varios menús, dale un nombre: aria-label="Principal".
    2. Una lista <ul>, porque un menú es una lista de enlaces. Se le quitan las viñetas con list-style: none y el margen con margin: 0; padding: 0.
    3. Cada opción, un <li> con un <a>. El enlace lleva el display: block y el relleno, para que toda la zona sea pulsable.
    4. La página actual se marca con aria-current="page", y en el CSS se pinta con el selector [aria-current="page"].
    5. Teclado: todo lo que hagas en :hover, hazlo también en :focus-visible.
